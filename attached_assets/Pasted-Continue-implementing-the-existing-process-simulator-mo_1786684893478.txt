## Goal

Implement Simulation Scenario management.

A Scenario represents the assumptions and configuration for a what-if simulation.

## Scenario fields

Scenario:

- scenario_id — UUID generated by backend
- name — human-readable scenario name
- model_ref — BPMN process model reference
- parameters — JSONB
- metadata — JSONB
- constraints — JSONB
- created_at
- updated_at

Parameters may contain:

- Task durations
- Gateway probabilities
- Resource pools
- Other simulation parameters

Metadata may contain:

- Author
- Tags
- Description

Example tags:

- baseline
- stress-test
- optimistic
- pessimistic

Constraints may contain:

- Maximum tokens
- Time horizon
- Other simulation limits
