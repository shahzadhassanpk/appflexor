# Governing Bodies

## Purpose

Use **Governing Bodies** to define the owner teams responsible for process approvals and policy. Each process is assigned a Governing Body so users can clearly identify the team accountable for its oversight and governance.

---

## Configure a Governing Body

1. Open **Orchestrate Configuration** from the Control Panel.
2. Select **Governing Bodies**.
3. Choose **Add New**.
4. Enter a clear **Title** and a unique **Key**.
5. Save the Governing Body.

You can edit or delete a Governing Body from the same list. Assign the appropriate Governing Body when creating or updating a process map.

---

## Good Practice

- Use a name that identifies the accountable team, such as *Risk & Compliance* or *Operations Leadership*.
- Create one governing body per approval and policy owner; avoid overlapping ownership.
- Assign every process to a governing body so responsibility remains clear as the process catalogue grows.
